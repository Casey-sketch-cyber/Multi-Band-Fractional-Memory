## 4. 数学内容（写进新稿第 3–4 节和附录 A）

记号沿用现稿：线性插值 X_lin，增量 d，增量可见性 ν，缺口左右观测端点 a < b，L = b − a，缺口帧数 g = L − 1。

### 4.1 回火 GL 核族

```math
a_0(\beta)=1,\qquad a_k(\beta)=a_{k-1}(\beta)\,\frac{\beta+k-1}{k}=\frac{\Gamma(k+\beta)}{\Gamma(\beta)\,\Gamma(k+1)},\qquad
\omega_k(\beta,\lambda)=a_k(\beta)\,e^{-\lambda k},\quad k=0,\dots,K-1 .
```

归一化后 w_k = ω_k / Σ_q ω_q。特例：

| 参数 | 得到的核 |
|---|---|
| λ = 0，0 < β < 1 | 现稿的截断 GL 幂律核 |
| β = 1，λ > 0 | 指数（几何）核，GRU-D 式衰减 |
| β = 1，λ = 0 | K 抽头均匀窗（现稿的 97 帧对照） |
| β → 0 | 瞬时核（权重集中在 k = 0） |

### 4.2 命题

**P1（闭式性质）。**

```math
\text{(a)}\ \ \sum_{k\ge 0}a_k(\beta)z^k=(1-z)^{-\beta}\ (|z|<1)
\ \Rightarrow\ \sum_{k\ge0}\omega_k=(1-e^{-\lambda})^{-\beta},\quad
\bar k=\frac{\beta}{e^{\lambda}-1},\quad \operatorname{Var}(k)=\frac{\beta e^{\lambda}}{(e^{\lambda}-1)^2}\quad(\lambda>0).
```

即 λ > 0 且不截断时，归一化权重是参数 (β, 1 − e^{−λ}) 的负二项分布。

```math
\text{(b)}\ \ \lambda=0:\quad \sum_{k=0}^{K-1}a_k(\beta)=\frac{\Gamma(K+\beta)}{\Gamma(K)\,\Gamma(\beta+1)},\qquad
\bar k_K=\frac{\beta\,(K-1)}{\beta+1}.
```

```math
\text{(c)}\ \ a_k(\beta)\sim \frac{k^{\beta-1}}{\Gamma(\beta)}\quad (k\to\infty).
```

证明要点：(a) 是二项级数。(b) 用 Σ_{k≤n} a_k(β) = a_n(β+1) 和 k·a_k(β) = β·a_{k−1}(β+1)。(c) 是 Gamma 函数比的渐近式。
用途：给每个核一个可比的"记忆尺度"（平均滞后），据此构造平均滞后匹配的指数对照（K4），并说明 β 在 λ = 0 时从瞬时核单调过渡到均匀窗。
另外写明：a_k(β) 正是分数差分算子 (1 − B)^{−β} 的 MA(∞) 系数，β < 1/2 对应平稳长记忆；现稿的 β 取到 0.9，靠硬截断才可和，回火给出一个可学习的平滑截断。

**P2（端点桥是投影加累加）。** 对缺口上的残差增量 r = (r_{a+1}, …, r_b) ∈ R^L，

```math
c_t=\sum_{u=a+1}^{t}\big(Pr\big)_u,\qquad P=I-\tfrac1L\mathbf 1\mathbf 1^{\top},\qquad a<t<b,
```

P 是到"净位移为零"子空间的正交投影。于是：c_a = c_b = 0；算子幂等；且

```math
|c_t|\le\sqrt{\tfrac{(t-a)(b-t)}{L}}\ \|r\|_2\le\tfrac{\sqrt L}{2}\|r\|_2,\qquad
|c_t|\le\tfrac{2(t-a)(b-t)}{L}\ \|r\|_\infty\le\tfrac L2\|r\|_\infty .
```

证明要点：c_t 是 r 与向量 v_t 的内积，v_t 前 t − a 个分量为 1 − (t−a)/L，其余为 −(t−a)/L；分别算它的 2-范数和 1-范数。
用途：端点约束不再只是一个恒等式，而是一个有界、非扩张的线性算子，修正幅度有显式上界。这是随机游走到离散桥的确定性对应。

**P3（零空间与对照组退化）。** 桥算子（取 t = a+1, …, b−1）的零空间恰为常数增量张成的一维空间。推论：

1. 缺口内 d 为常数（线性插值的斜率），所以特征里的"−d_t"项对本通道修正量没有贡献，起作用的只有掩码平均随 t 的变化。
2. 核的支撑覆盖整段窗口且权重均匀时，掩码平均不随 t 变，本通道修正量为零。对 128 帧窗口和 97 抽头均匀窗，t ∈ [31, 97] 的缺口帧属于这种情形。
3. W 抽头均匀窗在缺口内的盲区帧数为 max(0, g + 3 − 2W)（缺口两侧各至少有一个可见增量时）。

证明要点：部分和全为零且总和为零，推出去均值后的增量为零。
用途：解释 D3，并给出"公平有限窗"的选窗条件 W ≥ (g_max + 3)/2。

**P4（无目标泄漏）。** 适配器输出只依赖 (M, M ⊙ X)。证明：X_lin 只由观测值决定；ν_t = M_t M_{t−1} 把任何涉及未观测帧的增量从分子分母同时去掉。现有的隐藏目标扰动测试是它的数值对应。

**P5（可选）。** 由掩码平均是凸组合得 |h| ≤ 2 max|d|，结合 P2 得到整个适配器修正量的显式上界。

P1–P3 已由 [check_kernel_claims.py](check_kernel_claims.py) 数值核对通过。T1.1 负责把证明写完整。
