# Post-Confirmatory Duration Metrics

These files support the exploratory duration-response analysis reported in
Section 4.4 of the manuscript. The duration grid was specified after the
focused held-out test and must not be interpreted as an independent
confirmatory experiment.

- `gap_sweep_bootstrap.csv`: paired MPJPE bootstrap summary by gap duration.
- `gap_sweep_metric_bootstrap.csv`: MPJPE, velocity, and relative bone-length
  summaries and confidence intervals by gap duration.
- `gap_sweep_summary.json`: aggregate duration-response metadata.

The files were copied without modification from the retained remote experiment
archive on 3 September 2026.
